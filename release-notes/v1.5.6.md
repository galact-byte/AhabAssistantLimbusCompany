# Ahab Assistant Limbus Company v1.5.6

本次修复镜牢寻路失败后的一类恢复死循环（对应 issue #893），无限镜牢在后台键盘寻路模式下不再因偶发寻路失败而卡死、只跑 1 个镜牢就停。

## 🛠️ 修复

- 修复镜牢寻路失败后「重进镜牢」恢复分支死循环、约 70~90 秒被卡死保护杀线程的问题。根因是恢复分支里「回到窗口」按钮在 1600x900 下相似度约 **0.78**，正好卡在默认 **0.8** 点击门限下方，导致永远点不上「回到窗口」，只能反复点右上角设置齿轮（相似度 0.89）反复开关暂停菜单。现已把「回到窗口 / 放弃确认」两个重进按钮的点击门限下调到 0.7，恢复流程能真正退出并重进镜牢。
- 增强寻路模型（ONNX）偶发无检测时的健壮性：识别不到任何节点、或未定位到公交车节点时，路线图规划直接返回空路径并回退到常规/最远距离寻路，不再抛异常把整轮寻路带崩。
- 恢复分支在检测到「仍停在镜牢地图上」时，改为用键盘方向键重新选节点并进入，作为兜底，避免空点设置齿轮空耗到卡死保护。

## 🔄 兼容性说明

- 本版本面向 Windows x86_64 / Steam / 1600x900，无限镜牢 + 键盘寻路（`mirror_keyboard_navigation`）场景验证。
- 键盘兜底仅在确认位于镜牢地图（legend 强信号）时触发，对鼠标模式与非地图状态无副作用；无需改动任何配置即可生效。
- 说明：部分玩家反馈「游戏内分辨率显示 640x480 / 窗口无法手动拖动」，经日志核对属于后台模式下工具为防误触把窗口设为无边框固定所致的手动体验，并未影响识别（真实地图帧模板相似度 0.94），本版本不改动该行为；如需手动拖动窗口可在设置中关闭「减少误触」。

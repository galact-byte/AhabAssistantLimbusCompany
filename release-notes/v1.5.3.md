# Ahab Assistant Limbus Company v1.5.3

## 🛠️ 修复与优化

- 修复新版中文“服务器发生错误，请稍后再试”弹窗的单按钮变体：仅显示“重试”时，会基于当前帧 OCR 定位并在按钮可用时自动点击，不再因缺少“关闭”按钮而遗漏恢复。
- 优化双按钮“关闭 / 重试”弹窗的恢复顺序：可用“重试”会继续按 5 秒节流自动点击；游戏显示“重试N”倒计时时等待游戏自身恢复；只有“重试”持续灰化 15 秒后才关闭弹窗并自动重启。
- 服务器错误弹窗现在优先于常规卡死检测处理，避免网络恢复期间被普通超时逻辑提前打断。

## 🔄 兼容性说明

- 支持项目提供的标准 16:9 窗口分辨率，包括 1600×900 与 1920×1080；本次弹窗按钮通过当前帧 OCR 坐标定位，不使用固定的 1920×1080 点击坐标。
- 面向 Windows x86_64 环境；不新增依赖，不需要迁移既有配置或存档。

## ✅ 验证

- 已以单按钮及双按钮服务器错误截图完成离线 OCR 识别验证。
- 自动化回归测试、全量 pytest 和 Ruff 检查均已通过。

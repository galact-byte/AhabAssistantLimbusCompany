# Ahab Assistant Limbus Company v1.5.5

## 修复

修复启动时自动同步上游图片资源，误删本 fork 新增图片，导致纽本选关卡住、镜牢寻路失败的问题。

图片资源自动同步默认关闭，发布包已包含所需图片，无需单独热更新。

## 升级说明

面向 Windows x86_64／Steam／1600×900。旧配置可能仍开启自动同步，请在设置页关闭“自动更新图片资源”，或将 `%APPDATA%\AALC\config.yaml` 中的 `image_resource_sync` 设为 `False`。新安装默认关闭。

仍可手动开启同步，但上游图片清单可能不包含本 fork 的资源，存在再次误删的风险。

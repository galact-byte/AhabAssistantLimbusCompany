# Ahab Assistant Limbus Company v1.5.5

## 🛠️ 修复

- 修复纽本（纺锤经验本）在选关界面死循环、卡住不动的问题。根因是图片资源 OTA 自动同步指向上游作者的图床仓库（`KIYI671/AALCImageResources`），那份清单缺少本 fork 新增的锚点图 `thread_enter_up80_assets.png`，启动同步时把本地这张图当“多余文件”删掉，导致代码加载不到、进不了关卡。
- 同一原因还会误删镜牢寻路用的 `focused_encounter.png`、`risky_encounter.png`、`not_passed_floor.png`，一并修复。

## ✨ 变更

- 图片资源自动同步（`image_resource_sync`）默认改为**关闭**。发布包（7z）已整包自带全部图片资源，无需 OTA 热更；而 OTA 指向的是本 fork 无法控制的上游图床，开启只会因清单落后而误删本地新图。
- 如需保留旧行为，可在设置页手动打开“自动更新图片资源”，或在 `config.yaml` 把 `image_resource_sync` 改回 `True`。

## 🔄 兼容性说明

- 本版本面向 Windows x86_64 / Steam / 1600x900。
- 从旧版本升级时，若你的 `%APPDATA%\AALC\config.yaml` 里 `image_resource_sync` 仍为 `True`，建议手动改为 `False`（或在设置页关闭），否则启动同步仍可能删除本 fork 新增的图片资源。全新安装默认即为关闭。
- 本 fork 不与上游 `KIYI671` 的代码仓库或图床仓库同步；发版时通过打包整包携带资源，不依赖上游 OTA。

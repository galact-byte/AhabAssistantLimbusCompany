# Ahab Assistant Limbus Company v1.5.4

## ✨ 新增与优化

- 打包版把 `config.yaml`、主题包列表、主题包权重和配置备份固定到 `%APPDATA%\AALC`。换到新解压目录后会尽量从旁边的旧安装目录迁入已有配置，不再每次重配。
- 应用内检查更新默认走本 fork（`galact-byte/AhabAssistantLimbusCompany`）的 GitHub Release，不再把作者仓库的旧版本误判成“已是最新”。
- 设置页的项目主页和反馈入口改为本 fork。

## 🛠️ 修复

- 修复镜牢地图右上角金币 HUD 被当成商店的问题：必须同时看到商店专属控件、且没有“正在探索第N层”/地图图例证据，才会进入商店。
- 修复误进商店后无法离开、反复重启游戏的问题：已经回到地图时结束离开循环，不再报「无法退出商店」并关游戏重开。
- 修复 1600x900 下地图图例约 0.777、默认 0.8 认不出地图、键盘寻路进不去的问题。商店、寻路、奖励卡、主题包、战斗结束和回主界面统一按 0.75 识别地图。
- 修复后台点击模式下 farthest 寻路被直接跳过的问题：会尝试后台滚轮缩放；滚轮无效则降级到进门后备，不再立刻重进镜牢。

## 🔄 兼容性说明

- 本版本面向 Windows x86_64 / Steam / 1600x900。源码开发仍把配置写在当前目录；只有打包版使用 `%APPDATA%\AALC`。
- 首次打开打包版 1.5.4 时，若 `%APPDATA%\AALC\config.yaml` 还不存在，会尝试从旁边的旧安装目录复制配置。请先打开一次新版本，确认设置还在，再删旧目录。
- 应用内更新现在检查本 fork 的 Release。Mirror酱 仍可手动选择，但作者上游资源不一定包含本 fork 的修复。
- 镜牢商店误判、离开恢复和 0.777 地图识别已通过自动化回归；真商店模板偏低时可能跳过一次购物（漏一次优于关游戏重启）。后台滚轮是否被 Unity 接受，需实机确认；失败时只会降级，不会立刻重开。
- 不与作者上游 `KIYI671/AhabAssistantLimbusCompany` 的 main 同步。本 fork 继续作为 Steam 挂机线。

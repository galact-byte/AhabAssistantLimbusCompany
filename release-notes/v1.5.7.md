# Ahab Assistant Limbus Company v1.5.7

本次修复两处会导致「挂机中途软件自己退出」的问题：一是日常任务失败后 AALC 被误判为「已完成并配置退出」而自动关闭；二是纽本 / 镜牢里献祭类事件的首个选项在祭品耗尽后不可用，脚本会一直空点直到判失败。两者叠加，表现为跑到某个事件后战斗被取消、随即 AALC 无提示自动关闭（游戏仍开着）。

## 🛠️ 修复

- 修复任务失败后 AALC **自动退出软件**的问题。根因是任务序列提前失败时内部返回 `False`，而判断「是否执行完成后退出」用的是 `ret == 0`，Python 中 `False == 0` 恒为真，导致即使「完成后动作」选择了「什么也不做」，任务一旦失败也会触发退出。现改用独立的退出哨兵（`is` 身份判定），失败只会停在 AALC 界面等待人工查看，绝不再自动关闭软件。
- 修复献祭类事件（如「献上土偶 / 献上罪人」）卡死的问题。当首个选项因祭品 / 道具耗尽而变为不可用、但灰化检测未能识别其禁用状态时，旧逻辑会持续空点首项直到连续 8 次未推进而取消整场战斗。现增加兜底：首项连续多次点击仍未推进时，自动改点第二个候选（该类事件的次项通常始终可用），事件得以正常推进，不再把一整轮日常 / 镜牢带崩。

## 🔄 兼容性说明

- 两项修复均无需改动任何配置即可生效，面向 Windows / Steam 挂机场景。
- 「完成后动作」的既有行为不变：仅当你显式选择「退出 AALC / 关机 / 睡眠」等动作且任务**正常完成**时才会执行；任务失败不再误触发。
- 事件选项兜底遵循「可用首项不跳项」原则：可用的首项仍会在第一次点击就被选中，只有在首项连续多次确实点不动时才升级到次项，对正常事件无副作用。
